# ionpower-node 0.4

Fourth tagged release. The biggest single-session **Node interface
expansion** since the project started. Unlocks chalk-class terminal
libraries, the WHATWG URL ecosystem, and widens the vendor resolver
so bare `require('lib-name')` Just Works.

## What's new since v0.3

### Runtime (major)

- **WHATWG `URL` + `URLSearchParams`** polyfill exposed as globals.
  Parses protocol/host/hostname/port/pathname/search/hash/origin/
  href + username/password + searchParams, plus `keys()`/`values()`/
  `entries()`/`sort()`/`forEach()`. Relative resolution for common
  shapes. Not spec-complete.
- **Vendor-path require fallback**: when a bare specifier can't
  resolve through node_modules, walk the caller's directory up to
  root looking for sibling `<ancestor>/<spec>.js` or
  `<ancestor>/vendor/<spec>.js`. Any library vendored in the tree
  now resolves via its bare require without per-library patching.
- **`util.promisify`** (+ `.custom` symbol), **`util.callbackify`**,
  expanded **`util.types`** (`isDate`/`isRegExp`/`isPromise`/`isMap`/
  `isSet`/`isNativeError`/`isArrayBuffer`/`isUint8Array`/`isTypedArray`),
  and 13 top-level legacy `util.isXxx` aliases.
- **`supports-color`** and **`has-ansi`** seeded as fake packages.
  `supports-color.stdout` reflects `process.stdout.isTTY + TERM`.
- **`safe-buffer`** shim that re-exports the built-in Buffer.
- **`Error.captureStackTrace`** shim (attaches `.stack` as own
  property — error-ex / json-parse-even-better-errors require this
  shape).
- **`process`** expansion: `hrtime()`/`hrtime.bigint`, `uptime`,
  `title`, `versions` (`node`/`ionpower`/`spidermonkey`/`v8`),
  `release`, `memoryUsage`, `umask`.
- **`global` alias** alongside `window`/`self`.

### Build

- **Makefile** now passes `-isysroot /Developer/SDKs/MacOSX10.4u.sdk`
  to both compile and link steps (overridable via `MACOSX_SDK`).
  Fixes builds on hosts with an incomplete `/usr/include/sys/`.

## Tarballs

    sudo tar -xzf ionpower-node-0.4-gN-ppc.tar.gz -C /opt

Then:

    /opt/ionpower-node-0.4/bin/node <script.js>

Expects the matching `/opt/mozjs-45-ionpower-g{3,4,5}/` on the
target host.

## Known limitations

- `stream` is still a pass-through stub. `tape` remains parked.
- `luxon` needs `Intl` which SM45 was built `--without-intl-api`.
- `wrap-ansi`'s ANSI-aware branch needs ES2018 named capture groups.
- `http`/`https`/`net` are still sync-only or missing.
- No `fetch`, no `AbortController`.
