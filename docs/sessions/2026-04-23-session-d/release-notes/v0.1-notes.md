## What's in the tarball

```
ionpower-node-0.1-gX/
├── bin/
│   ├── ionpower-node    (the binary; ~1.3 MB)
│   └── node -> ionpower-node
└── share/ionpower-node/
    └── vendor/
        └── babel.js     (@babel/standalone 7.23.9 for the
                          transpile-on-require fallback)
```

## Runtime dependency

Binary is dynamically linked to `libmozglue.dylib` from the matching
`/opt/mozjs-45-ionpower-g{3,4,5}/`. Build scripts for mozjs are in
the repo under `scripts/install-mozjs-45-ionpower-g{3,4,5}.sh`.

## Highlights

- CommonJS `require()` with node_modules walk-up
- Transpile-on-require via @babel/standalone for modern JS (?. ?? spread)
- Core modules: fs (sync), path, buffer, crypto (SHA-256 / HMAC-SHA-256),
  events, util, os, stream (stub), http (curl shell-out), timers
- Polyfills: Promise (synchronous; no event loop), TextEncoder/Decoder,
  Array.prototype.flat, Object.entries / values / fromEntries, ...
- IonPower JIT active: 5M integer-sum loop runs in 47 ms on a G4
