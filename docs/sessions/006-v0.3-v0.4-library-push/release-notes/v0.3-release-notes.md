# ionpower-node 0.3

Third tagged release. **Crossed the 300-library milestone.**

## What's new since v0.2

### Runtime

- `Error.captureStackTrace` shim in the bootstrap. V8-specific static
  that Node-style libraries reach for inside their custom Error
  subclass constructors. Without it, both error-ex and
  json-parse-even-better-errors threw at require time. The shim
  attaches `.stack` as an own (not prototype) data property so
  `Object.getOwnPropertyDescriptor(this, 'stack')` returns a
  descriptor — error-ex specifically depends on that shape.

## Tarballs

Each tarball installs to `/opt/ionpower-node-0.3/`. Expects the
matching `/opt/mozjs-45-ionpower-g{3,4,5}/` on the target host.

    sudo tar -xzf ionpower-node-0.3-gN-ppc.tar.gz -C /opt

Then:

    /opt/ionpower-node-0.3/bin/node <script.js>

## Known limitations

- normalize-url: needs the WHATWG URL constructor which SM45 doesn't
  ship. Vendored but unsmoked.
- luxon: Intl-dependent (SM45 built --without-intl-api).
- callsites + parent-module: V8's Error.prepareStackTrace only.
- wrap-ansi ANSI-aware branch: ES2018 named capture groups.
- tape: still parked (real Writable stream needed).
