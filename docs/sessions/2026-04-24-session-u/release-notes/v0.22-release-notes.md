# ionpower-node 0.22 — JWK + AES-KW

Extends crypto.subtle with two commonly-expected WebCrypto features.

## What's new

### JWK (JSON Web Key) format

`subtle.importKey('jwk', …)` and `subtle.exportKey('jwk', key)` for
symmetric keys. Output shape:

```js
{
    kty: 'oct',
    k:   'AQIDBAUGBwgJCgsMDQ4PEA',          // base64url of raw bytes
    ext: true,
    key_ops: ['encrypt', 'decrypt'],
    alg: 'A128CBC'                          // derived from algorithm
}
```

`alg` is set to the matching JWA identifier — `A128CBC` / `A192CTR` /
`A256GCM` for AES, `HS256` / `HS384` / `HS512` for HMAC.

### AES-KW (RFC 3394)

`subtle.wrapKey(format, key, wrappingKey, wrapAlg)` and
`subtle.unwrapKey(format, wrapped, wrappingKey, wrapAlg, keyAlg, extractable, usages)`
for AES key wrapping. Tamper-detection via the `A6A6...A6` IV check —
a wrong KEK or tampered ciphertext produces an IV mismatch and throws.

128/192/256-bit KEK sizes all supported. Input key data must be a
multiple of 8 bytes (64 bits).

## Verified in tests

- JWK round-trip (import → export → import preserves bytes)
- AES-KW wrap: 16 bytes → 24 bytes, round-trip unwraps to original
- AES-KW tamper detection: wrong bytes → throws on unwrap
