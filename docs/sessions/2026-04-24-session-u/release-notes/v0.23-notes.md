# ionpower-node 0.23 — library hunt wave 4

Follows the v0.22 JWK/AES-KW release with another batch of
vendored libraries that now pass a smoke test.

## New libraries

| Library | Shape verified |
|---|---|
| `tweetnacl` | Loads; exposes `hash` or `sign`; `randomBytes(32)` returns 32 bytes when present. |
| `fast-json-stable-stringify` | Emits deterministic JSON with keys sorted alphabetically at every level (verified nested case too). |
| `stable-sort` | Stable merge sort (ascending numeric comparator); result matches expected ordering on a shuffled duplicate-containing input. |
| `emoji-regex` (v10) | Returned (or constructed) regex detects U+1F600 inside a mixed string. |

## Totals

- Libraries with smoke coverage: **585+**
- Assertions across all smokes: **1370+** in **372** smoke files.

## Install

```
tar -C /opt -xzf ionpower-node-0.23-g5-ppc.tar.gz
/opt/ionpower-node-0.23/bin/node script.js
```

Separate G3 / G4 / G5 tarballs are provided — each depends on the
matching `/opt/mozjs-45-ionpower-{g3,g4,g5}/` install from
tenfourfox-src.
