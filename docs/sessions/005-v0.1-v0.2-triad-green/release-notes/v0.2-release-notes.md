# ionpower-node 0.2

Second tagged release. Builds on v0.1 by adding 30 more libraries
(ending at 268), hardening a handful of Node-compat rough edges
that the library triage surfaced, and shipping a small 6-library
composition demo.

## What's new

### Runtime

- `process.umask`: returns Node's default `0o022` so
  `_0777 & ~process.umask()` (mkdirp-class recipes) works.
- `global` alias in the bootstrap alongside `window` / `self`.
  xmldoc, webpack-style UMDs, and other Node-ish bundles that
  test `typeof global !== 'undefined'` now resolve correctly.
- `fs` errors carry Node-style `.code` / `.errno` / `.syscall`
  / `.path`. mkdirp-classic and every library that branches on
  `err.code === 'ENOENT'` now recovers as expected. Wired
  through `mkdirSync`, `statSync`, `unlinkSync`, `rmdirSync`,
  `readFileSync`.

### Libraries (+30)

- Edit distance: js-levenshtein, leven, fastest-levenshtein
- Text/terminal: ansi-regex, strip-ansi, ansi-styles,
  string-width, is-fullwidth-code-point, strip-indent, redent,
  min-indent, pretty-ms, pupa, linkifyjs
- Paths/globs: is-glob, is-extglob, slash, normalize-path
- Objects/keys: map-obj, sort-keys, is-plain-obj (3.x CJS),
  camelcase-keys, decamelize-keys, quick-lru
- Hashing: hash-sum, color-hash
- Case: Case (Nathan Bubna, omnibus snake/camel/pascal/...)
- Templates: twig
- Async: p-limit
- Format: xmldoc (parsed via pure-JS sax parser API)
- Misc: shell-quote, is-email, mkdirp-classic

### Composition demo

`demos/feed-report/report.js` — reads an offline RSS file and
prints a colorized, width-aligned summary. Chains xmldoc +
ansi-styles + strip-ansi + string-width + color-hash +
pretty-ms.

## Tarballs

Each tarball installs to `/opt/ionpower-node-0.2/`. Expects the
matching `/opt/mozjs-45-ionpower-g{3,4,5}/` to already be present
on the target host.

    sudo tar -xzf ionpower-node-0.2-gN-ppc.tar.gz -C /opt

Then:

    /opt/ionpower-node-0.2/bin/node <script.js>
