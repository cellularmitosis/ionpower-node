# ionpower-node v0.83

**HTTPS support is real.** This release adds the `tls` and `https`
modules, linked against OpenSSL 1.1.1t, with a TLSSocket that wraps
`net.Socket` and pumps bytes through a memory BIO pair. From your
code's point of view, `https.request` and `https.createServer` work
exactly like Node's:

```javascript
var https = require('https');
https.get('https://example.com/', function (res) {
    res.on('data', chunk => /* decrypted bytes */);
});
```

`fetch('https://...')` no longer falls back to a sync curl shim — it
uses the same async TLS path as `https.request`.

## What's new

- **`tls` module**: `tls.connect`, `tls.createServer`, `tls.TLSSocket`,
  `tls.createSecureContext`, `tls.generateSelfSigned`. SNI, TLS 1.2 +
  1.3, peer cert verification against the bundled CA bundle at
  `/opt/ca-certificates-20230110/share/cacert.pem`.
- **`https` module**: real async `https.request` / `https.get` /
  `https.createServer` over `tls.TLSSocket` + the same HTTP/1.1
  parser as `http`.
- **`fetch()`** now uses `https.request` for `https://` URLs (was
  falling back to sync curl).
- **`process.versions.openssl`** populated from the linked OpenSSL.
- **TLS introspection**: `socket.getProtocol()`, `getCipher()`,
  `getPeerCertificate()` on `TLSSocket`.
- **`tls.generateSelfSigned(commonName, days)`** — RSA-2048 keygen +
  X.509 self-sign helper for demos and testing.

## New demo

`demos/https/` — minimal HTTPS server (self-signed cert, three routes)
+ CLI client (auto-`-k` for localhost; works against any public HTTPS
URL). See [`demos/https/README.md`](https://github.com/cellularmitosis/ionpower-node/blob/main/demos/https/README.md).

## Bug fixes

- **`_Socket.end()` race on Tiger PPC.** Calling `shutdown(SHUT_WR)`
  in the same event-loop tick as `write()` to a remote socket dropped
  in-flight bytes — the peer received FIN with no data and returned
  no response. `http.request` to remote servers was silently failing
  because of this. Fix: defer the shutdown by one timer tick
  (`setTimeout(0)`), enabling the kernel to actually transmit the
  buffered data first. Also enabled `TCP_NODELAY` by default in
  `_Socket._onConnected`. Locally-talking code (`http_async_smoke`,
  the chat / paste / express-chat demos) was unaffected because
  loopback doesn't have this race.

## Prerequisite

OpenSSL 1.1.1t must be installed at `/opt/openssl-1.1.1t/` and the
default trust bundle at `/opt/ca-certificates-20230110/share/cacert.pem`.
Two ways to install:

```bash
# Option 1: tiger.sh (project-friendly Tiger PPC pkg manager)
tiger.sh install openssl-1.1.1t

# Option 2: leopard.sh tarballs (G3 example; swap g3 -> g4 / g5 as needed)
cd /opt
curl http://leopard.sh/dist/ca-certificates-20230110.tar.gz | gunzip | tar x
curl http://leopard.sh/binpkgs/openssl-1.1.1t.tiger.g3.tar.gz | gunzip | tar x
```

See [`BUILDING.md`](https://github.com/cellularmitosis/ionpower-node/blob/main/BUILDING.md)
for the full install walkthrough.

## Smokes

Three new smokes wired into `make test-all`:

- `test/tls_smoke.js` — `tls.connect` to example.com:443; verifies
  protocol, cipher, peer cert, GET round-trip.
- `test/https_get_smoke.js` — `https.get` round-trip with HTTP body
  parsing.
- `test/https_server_smoke.js` — generates a self-signed cert,
  brings up an HTTPS server, makes a self-loop request through it.
