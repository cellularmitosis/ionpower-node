# ionpower-node 0.7 — crossed 500 libraries

Third-party libraries with passing smokes: **453 → 501**.
Assertions: **1146 → 1186**. Validated on G3 / G4 / G5.

This was the big **Node-interface expansion** release. Timer queue,
real Stream classes, async fs, and expanded crypto land together —
enough of Node's event-loop surface for a lot of libraries that used
to bounce off v0.5 to just work now.

## Runtime additions

- **Timer queue + main.cpp drain.** `setTimeout(fn, 0)` and
  `setImmediate` now enqueue into `__timer_queue__` and drain in
  `fireAt` order after the entry script returns. Ordering is correct;
  wallclock delays still collapse (documented).
- **Real Stream classes.** `Readable` / `Writable` / `Duplex` /
  `Transform` / `PassThrough` with proper `_read` / `_write` / `push`
  / buffering. Plus `stream.pipeline()` and `stream.finished()`.
- **Async fs.** Every `*Sync` method has a `setImmediate`-wrapped
  callback twin. `fs.promises.*` is the Promise wrap. `fs.constants`,
  `fs.access`, `fs.realpath` round out the surface.
- **Crypto family.** `sha1` via RFC 3174; `createHmac` now accepts
  md5/sha1/sha256; `pbkdf2Sync` + `pbkdf2` over the HMAC. RFC vectors
  verified (FIPS 180-1, RFC 2104, RFC 2202, RFC 6070). bcryptjs runs
  end-to-end.
- **Core-module aliases.** `readable-stream` → built-in `stream`.
  `inherits` → `util.inherits`. Dozens of stream-tree libraries that
  bare-require these just work.

## Composition demo

`demos/log-scan/app.js` — scans an Apache common-log-format file,
groups by status-code class, writes a colored table + JSON sidecar.
Chains eight pieces of the new surface end-to-end: `stream.Transform`
+ `split2` + `fs.writeFile` (async cb) + `crypto.createHash('sha1')`
+ `chalk` + `hash-sum` + `text-table` + `pretty-ms`. Auto-generates
a 100-line synthetic log so it works offline.

## Known quirks

- **Pipe auto-resume.** Adding a `'data'` listener flips a Readable
  into flowing mode and immediately drains. `src.pipe(dst)` works end-
  to-end for data, but `dst.end()` isn't called via the pipe in our
  impl — consumers that rely on `pipe`-initiated `end()` need to call
  it explicitly. Stream-libs smoke uses direct `.write()`/`.end()`.
- **Wallclock delays collapse.** `setTimeout(fn, 1000)` fires in
  order relative to other pending timers, but doesn't actually wait
  1000ms. Tape/debounce/split2 etc. need the ordering guarantee, not
  the delay.
- **tape** still parked — wants `process.stdout` wired as a Writable
  emitting `'drain'`, plus 8 sibling files. Deferred to a future
  session.

## Install

Each tarball installs to `/opt/ionpower-node-0.7/`. Depends on a
matching `/opt/mozjs-45-ionpower*` build per CPU (G3 / G4 / G5).

```
sudo tar -C /opt -xzf ionpower-node-0.7-g5-ppc.tar.gz
/opt/ionpower-node-0.7/bin/node --version
```
