# ionpower-node 0.51 — `node:test` before/after hooks

Adds the four hooks Node's test runner exposes:

```js
const test = require('node:test');

test.before(() => { /* once before any test */ });
test.after(() => {  /* once after all tests  */ });
test.beforeEach(() => { /* before each test */ });
test.afterEach(() => {  /* after each test (even on failure) */ });

test('one', () => { /* ... */ });
test('two', () => { /* ... */ });
```

Hooks register into module-level arrays. The runner kicks off on
next-tick (same as v0.36); we wrap each queued entry in a
`beforeEach`/`afterEach` pair so they fire around every test, then
sandwich the whole queue between the `before` and `after` sets.

`afterEach` fires whether the test passed or threw — same as Node.

## Verified

A child run of two tests with all four hooks produces the expected
order:

```
before, beforeEach, one, afterEach, beforeEach, two, afterEach, after
```

TAP output unchanged: `ok 1 - one`, `ok 2 - two`, `# pass 2`.
