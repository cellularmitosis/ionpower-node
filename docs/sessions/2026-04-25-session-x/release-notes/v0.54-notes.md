# ionpower-node 0.54 — `stream.Readable.from` + `Readable.toArray`

Two Node 12+ / 18+ stream helpers.

## `stream.Readable.from(input)`

```js
const stream = require('stream');

stream.Readable.from([1, 2, 3]);          // emits 1, 2, 3, end
stream.Readable.from('hello');             // emits 'hello', end
stream.Readable.from(Buffer.from([1,2])); // emits the Buffer, end
stream.Readable.from(iterable);           // sync iterator or
                                          // Symbol.iterator-bearing
```

`Readable.from` defers each push via `setImmediate` so the caller
has a tick to attach `'end'` / `'data'` listeners before emissions
race ahead. Without that defer, sync push-and-emit beats user
`on('end', fn)` registration.

## `readable.toArray()`

```js
const items = await stream.Readable.from([1, 2, 3]).toArray();
// items = [1, 2, 3]
```

Promise that resolves with the array of all emitted chunks; rejects
on `'error'`.

## Verified

- `Readable.from([1,2,3]).toArray()` → `[1,2,3]`
- `Readable.from('hello')` emits one `'data'` event with the string
- `Readable.from(Buffer)` emits one Buffer chunk
- `Readable.from(array) | PassThrough` → `toArray` returns the same array
