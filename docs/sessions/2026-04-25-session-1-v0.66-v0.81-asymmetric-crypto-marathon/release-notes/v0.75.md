## What's new

### ECDSA on P-256 / P-384 / P-521 / secp256k1

The asymmetric crypto stack is now complete on the sign/verify side.
Up to v0.74 we had RSA + Ed25519 + X25519. v0.75 vendors `elliptic`
(the standard JS ECC implementation) and wires it into the existing
`crypto.{sign,verify,generateKeyPairSync}` API:

```js
var pair = crypto.generateKeyPairSync('ec', { namedCurve: 'P-256' });
var sig = crypto.sign('sha256', Buffer.from('hello'), pair.privateKey);
crypto.verify('sha256', Buffer.from('hello'), pair.publicKey, sig);  // true
```

Curves supported: `P-256` (`prime256v1` / `secp256r1`), `P-384`,
`P-521`, `secp256k1` (Bitcoin's curve). Hash algorithms: `sha1`,
`sha256`, `sha384`, `sha512`. KeyObjects carry
`asymmetricKeyDetails.namedCurve` for libraries that introspect.

### Performance heads-up

ECDSA is **slow** on G3:

| Op | G3 (900 MHz) |
|---|---|
| keygen   | ~100 ms |
| sign     | ~3 s    |
| verify   | ~13 s   |

`bn.js`'s bignum arithmetic isn't tuned for 32-bit PowerPC. Functionally
correct but expect to wait. RSA via forge is similarly slow. G4 / G5
are noticeably faster.

### Vendor layout

```
test/vendor/elliptic/
  package.json
  lib/elliptic.js + lib/elliptic/{ec,curve,curves,...}
  node_modules/{bn.js,brorand,hash.js,hmac-drbg,
                minimalistic-assert,minimalistic-crypto-utils}/
```

Total 452 KB. Installed under `share/ionpower-node/vendor/elliptic/`
by the Makefile install rule, so binary releases work out of the box.

### What's left

The `crypto` row's last "Still missing" item drops from "ECDSA / NIST
ECDH" to just "NIST ECDH". P-256 / P-384 ECDH key agreement isn't
wired yet — that needs `ec.derive(otherPubKey)` + a
`crypto.diffieHellman` shape. X25519 ECDH (via tweetnacl) does work.

## Setup (unchanged from v0.73)

```bash
# One-time mozjs install (skip if you already did this):
curl -L -O https://github.com/cellularmitosis/ionpower-node/releases/download/v0.73/mozjs-45-ionpower-g3.tar.gz
sudo tar xzpf mozjs-45-ionpower-g3.tar.gz -C /opt/

# v0.75 runtime
curl -L -O https://github.com/cellularmitosis/ionpower-node/releases/latest/download/ionpower-node-0.75-g3-ppc.tar.gz
sudo tar xzpf ionpower-node-0.75-g3-ppc.tar.gz -C /opt/
/opt/ionpower-node-0.75/bin/node --version
```

(Ditto with `g4`/`g5`.)
