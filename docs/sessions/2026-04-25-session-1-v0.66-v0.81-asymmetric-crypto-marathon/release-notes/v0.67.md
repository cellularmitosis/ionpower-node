## What's new

`crypto.X509Certificate` — Node-style X.509 wrapper over node-forge.

```js
var crypto = require('crypto');
var cert = new crypto.X509Certificate(pem);   // PEM string, PEM Buffer, or DER Buffer

cert.subject;            // 'CN=example.com\nO=ACME'
cert.issuer;             // same form
cert.validFrom;          // 'Apr 25 12:34:56 2026 GMT'
cert.validTo;
cert.serialNumber;       // 'AB12CD34...'
cert.fingerprint;        // 'AB:12:CD:34:...' (sha1)
cert.fingerprint256;     //   "  (sha256)
cert.fingerprint512;     //   "  (sha512)
cert.raw;                // DER as Buffer
cert.subjectAltName;     // 'DNS:foo.com, DNS:*.foo.com, IP Address:1.2.3.4'
cert.ca;                 // true if basicConstraints cA set
cert.publicKey;          // KeyObject — pass directly to crypto.verify

cert.toString();         // -> PEM
cert.toJSON();           // -> PEM
cert.checkIssued(other);
cert.checkPrivateKey(privateKO);   // compares RSA n + e
cert.checkHost('foo.com');
cert.verify(publicKO);   // forge.pki.verifyCertificateChain under the hood
```

## Smoke

`test/x509_smoke.js` generates a self-signed RSA-1024 cert via forge
with SAN (DNS + wildcard + IP) + basicConstraints cA=true, then asserts
every property + method matches Node's shape, including DER-Buffer and
PEM-Buffer construction paths. ~24 assertions.
