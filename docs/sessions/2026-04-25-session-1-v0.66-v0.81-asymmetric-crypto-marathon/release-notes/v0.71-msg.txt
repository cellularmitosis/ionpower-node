v0.71: t.mock + cluster stub + README accuracy pass

Two pieces:

1. node:test mock support. Each test gets its own `t.mock` tracker
   that auto-restores at end-of-test:
   - t.mock.fn(impl?) -> spy with .mock.calls / .callCount() /
                          .resetCalls() / .mockImplementation()
   - t.mock.method(obj, name, impl?) -> replaces obj[name],
                          auto-restored at test exit
   - t.mock.getter / .setter for property descriptors
   - t.mock.restoreAll / .reset

2. cluster: single-process degenerate stub. Real cluster needs a
   master + N worker processes sharing a TCP server fd; we have
   neither. Expose the master half so libraries that branch on
   `if (cluster.isPrimary)` take the right path:
   - cluster.isMaster / isPrimary = true
   - cluster.isWorker = false
   - cluster.workers = {}
   - cluster.fork() throws
   - cluster.setupMaster / setupPrimary
   - cluster.disconnect(cb) (cb fires)
   - EventEmitter base
