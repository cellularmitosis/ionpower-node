## What's new

### `fetch()` over HTTPS now handles binary bodies

Up to v0.72 the curl-shim HTTPS path tried to UTF-8 decode every
response body to populate `response.body`. For any binary content
(gzip tarballs, images, tar archives) the decode threw a JS
exception, poisoning the SpiderMonkey context — `response.bodyBytes`
never got set and `response.arrayBuffer()` returned 0 bytes.

v0.73 catches the failed decode, clears the pending exception, and
sets `response.body = ''` (so callers reading `.body` get a sane
empty string for binary content). `response.arrayBuffer()` and
`.buffer()` now return the real bytes.

Validated end-to-end on the new G3 build host (ibookg37, iBook G3
900 MHz) against the live npm registry:

```
fetch('https://registry.npmjs.org/mri/-/mri-1.2.0.tgz')
  → 4448 bytes; gzip magic 1f 8b at offset 0
  → zlib.gunzipSync → 18432 bytes, first tar entry = 'package/package.json'
```

This unblocks the [`examples/npm-fetch`](https://github.com/cellularmitosis/ionpower-node/blob/v0.73/examples/npm-fetch/) demo.

### **One-time** mozjs tarballs for the install path

Up to now this was undocumented: the runtime needs a matching
SpiderMonkey + IonPower JIT installed at
`/opt/mozjs-45-ionpower-{g3,g4,g5}/` beside `/opt/ionpower-node-<ver>/`.

This release ships **one-time mozjs tarballs** as GitHub artifacts.
Pull the appropriate one once and reuse it across all subsequent
ionpower-node releases:

| Arch | mozjs tarball | size |
|---|---|---|
| G3 (PPC 750)  | [`mozjs-45-ionpower-g3.tar.gz`](https://github.com/cellularmitosis/ionpower-node/releases/download/v0.73/mozjs-45-ionpower-g3.tar.gz) | 90 MB |
| G4 (PPC 7450) | [`mozjs-45-ionpower-g4.tar.gz`](https://github.com/cellularmitosis/ionpower-node/releases/download/v0.73/mozjs-45-ionpower-g4.tar.gz) | 66 MB |
| G5 (PPC 970)  | [`mozjs-45-ionpower-g5.tar.gz`](https://github.com/cellularmitosis/ionpower-node/releases/download/v0.73/mozjs-45-ionpower-g5.tar.gz) | 66 MB |

Plus the runtime tarballs as before:

| Arch | runtime tarball |
|---|---|
| G3 | `ionpower-node-0.73-g3-ppc.tar.gz` |
| G4 | `ionpower-node-0.73-g4-ppc.tar.gz` |
| G5 | `ionpower-node-0.73-g5-ppc.tar.gz` |

### Setup (full happy path)

```bash
# 1) One-time: install SpiderMonkey + IonPower JIT (G3 example)
curl -L -O https://github.com/cellularmitosis/ionpower-node/releases/download/v0.73/mozjs-45-ionpower-g3.tar.gz
sudo tar xzpf mozjs-45-ionpower-g3.tar.gz -C /opt/

# 2) Per release: install the runtime
curl -L -O https://github.com/cellularmitosis/ionpower-node/releases/latest/download/ionpower-node-0.73-g3-ppc.tar.gz
sudo tar xzpf ionpower-node-0.73-g3-ppc.tar.gz -C /opt/

# 3) Run
/opt/ionpower-node-0.73/bin/node --version
```

After step 1, future ionpower-node releases re-use the same
`/opt/mozjs-45-ionpower-g3/` and only need step 2.
