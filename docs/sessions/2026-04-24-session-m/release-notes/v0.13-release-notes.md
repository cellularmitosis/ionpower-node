# ionpower-node 0.13 — library hunt (504 → 560+)

After 5 releases of Node-surface work (v0.8–v0.12), this release is
pure library-count push. The new surface (real event loop, async
I/O, fetch, dns, microtask queue, SHA-512, HTTP chunked, stdin
streaming) unlocks a pile of libraries that were previously vendored
but unsmoked or just absent.

**504 → 560+ libraries**. ~1257 → **1315+** assertions.
Triad-validated.

## What's new

### Batch-smoked from existing vendor tree (~45 libs)

Libraries already vendored but never had smoke coverage — many lived
because some other smoke quietly used them — now have explicit tests:

**Tiny utilities:** indexof, foreach, xtend-mutable, object-assign-v5,
is-obj, is-primitive, min-indent, escape-string-regexp-v5, ms2,
json-parse-safe, json-stringify-safe, levenshtein, sprintf-js,
upper-case-first, no-case, sentence-case, utils-merge-v1, arrify,
has-ansi, cli-boxes, url-alphabet, colorette.

**Streams / plumbing:** unpipe, stream-shift, destroy, safe-buffer,
tiny-inflate (the inflate we embed for zlib, now also loadable as a
module).

**Data / config:** rc, cli-boxes, mime-db, mime-db-v2, spinners
(86 presets), defaults, bplist-parser-mini, require-directory.

**Parsers / validators:** sax-js, zod, joi-full, matcher, lazy,
fp-ts, crypto-js-core, chalk-template, jszip-utils, number-precision.

**Date / time / units:** moment-range.

**CLI frameworks:** sade.

### Fresh HTTP/cookie ecosystem (+10 libs)

Pairs with the async `http.createServer` + `fetch` landed in v0.10/v0.12:

- **cookie** 0.6 — parse/serialize HTTP cookies
- **set-cookie-parser** 2.6 — parse Set-Cookie response headers
- **cookie-signature** 1.2 — HMAC-signed cookie values
- **on-headers** 1.0 — run a function just before headers go out
- **delegates** 1.0 — EventEmitter delegation helper
- **ip** 1.1 — IPv4/IPv6 utilities (`isV4Format`, `toLong`, etc.)
- **content-type** 1.0 — RFC 7231 parser/formatter
- **content-disposition** 0.5 — `Content-Disposition: attachment; filename=…`
- **basic-auth** 2.0 — Authorization header parser
- **parse-ms** 3.0 — break ms into days/hours/minutes/seconds

### Skipped (known-incompatible)

- `dotenv`: needs a `../package.json` the vendor tree doesn't ship
- `readline-sync`: uses `process.binding()` which we don't expose
- `supports-color`: needs `has-flag` as a sibling module in a path
  our vendor resolver doesn't reach
- `json` package: needs `require('vm')` (not exposed)

All loaded with `try/catch` in the smokes; skip-and-continue when
incompatible, not a hard fail.

## Install

Each tarball installs to `/opt/ionpower-node-0.13/`.

```
tar -C /opt -xzf ionpower-node-0.13-g5-ppc.tar.gz
/opt/ionpower-node-0.13/bin/node script.js
```

## Known limitations (unchanged from v0.12)

- HTTPS through `fetch` uses the sync curl shim.
- No TLS in the net stack.
- zlib compression stubbed.
- scrypt stubbed.
- `process.nextTick` shares the microtask queue.
