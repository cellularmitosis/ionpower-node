  createServer / createConnection / isIP. IPv4-only for now.

  (createServer → IncomingMessage request + ServerResponse).

  variants, chunks emitted via setImmediate, pipe() works.
  Encoding, start/end slicing, 'w'/'a' flag.

  as a C++11 raw string in src/node_compat/zlib.cpp.

  Inflate. Compression still throws.
