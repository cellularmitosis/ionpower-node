# ionpower-node 0.46 — `timers/promises` + `dns/promises` + library hunt wave 15

## `require('timers/promises')`

```js
const { setTimeout, setImmediate } = require('timers/promises');

// Promise-based delay
const value = await setTimeout(50, 'hello');     // -> 'hello' after 50ms

// Cancellable via AbortSignal
const c = new AbortController();
const p = setTimeout(1000, 'wont resolve', { signal: c.signal });
c.abort();                                       // p rejects with AbortError
```

`setInterval` is NOT included — Node's variant returns an async iterator
which we can't synthesize without async generators (no `for await`).

## `require('dns/promises')` and `dnsModule.promises`

```js
const dns = require('dns/promises');
const { address, family } = await dns.lookup('localhost');
const a = await dns.resolve4('example.com');
```

- `lookup` resolves with `{ address, family }`.
- `resolve4` / `resolve6` return arrays.
- `reverse` rejects with explicit not-implemented (curl-backed sync
  DNS has no reverse path).

Also pinned on `dns.promises` to match Node.
