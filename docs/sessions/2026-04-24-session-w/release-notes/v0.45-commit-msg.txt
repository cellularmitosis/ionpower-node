v0.45: fs.cp / fs.rm (Node 14+ / 16+) + library hunt wave 14

fs.rmSync(path, options) — Node 14+
- options: { recursive, force }
- Recursively walks directories, falls through to unlinkSync
  for files. force suppresses ENOENT-on-missing. Matches the
  Node API including the EISDIR throw when a directory is rm'd
  without recursive: true.

fs.cpSync(src, dest, options) — Node 16+
- options: { recursive }
- Recursive copy: creates dest dir if missing, walks readdirSync,
  recurses on subdirs, falls through to copyFileSync for files.
  Throws EISDIR if src is a directory and recursive isn't set.

Both have async (callback-style) variants via the existing
_fsAsync wrapper: fs.rm(path, options, cb), fs.cp(src, dest, options, cb).
