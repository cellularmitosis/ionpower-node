# ionpower-node 0.45 — `fs.cp` / `fs.rm` + library hunt wave 14

## `fs.rmSync` / `fs.rm` (Node 14+)

```js
fs.rmSync('/tmp/dir', { recursive: true, force: true });
fs.rm('/tmp/dir', { recursive: true }, (err) => { ... });
```

- `recursive: true` walks directories; without it, throws `EISDIR`
  on a directory.
- `force: true` swallows `ENOENT` when the path doesn't exist.
- Single-file calls fall through to `unlinkSync`.

## `fs.cpSync` / `fs.cp` (Node 16+)

```js
fs.cpSync('/src', '/dest', { recursive: true });
fs.cp('/src', '/dest', { recursive: true }, (err) => { ... });
```

- Recursive copy: creates `dest` if missing, walks `readdirSync`,
  recurses on subdirs, falls through to `copyFileSync` for files.
- Throws `EISDIR` if `src` is a directory and `recursive` isn't set.

Async variants use the existing `_fsAsync` callback shape.
