# ionpower-node 0.40 — `util.styleText` + library hunt wave 9

## `util.styleText` (Node 21+)

```js
const util = require('util');

// Single style
util.styleText('red', 'error!');

// Array of styles
util.styleText(['red', 'bold', 'underline'], 'WARNING');

// Force ANSI even on non-TTY streams
util.styleText('red', 'x', { validateStream: false });

// Target a specific stream
util.styleText('green', 'ok', { stream: process.stderr });
```

Supports: `reset`, `bold`, `dim`, `italic`, `underline`, `blink`,
`inverse`, `hidden`, `strikethrough`, the 8 ANSI foreground colours
+ `gray`/`grey`, and all `bg*` variants. Unknown names throw
`TypeError`. Non-TTY streams return plain text unless
`validateStream: false`.
