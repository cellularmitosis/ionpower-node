# ionpower-node 0.49 — `EventTarget` / `Event` / `CustomEvent` globals

DOM-style EventTarget pump exposed on the global, plus `Event` and
`CustomEvent` constructors. Cross-target libraries (undici,
node-fetch internals, jose, various web-API polyfills) reach for
these without checking — now they don't ReferenceError.

## Surface

```js
const et = new EventTarget();
et.addEventListener('tick', e => { /* ... */ });
et.addEventListener('once', fn, { once: true });
et.removeEventListener('tick', fn);

const ev = new Event('click', { bubbles: true, cancelable: true });
ev.preventDefault();
et.dispatchEvent(ev);              // false if any listener prevented

const ce = new CustomEvent('ping', { detail: { x: 1 } });
ce.detail.x;                       // 1
```

Supports:

- `addEventListener` with `once` / `capture` flags
- `removeEventListener`
- `dispatchEvent` returning `!defaultPrevented`
- `preventDefault`, `stopPropagation`, `stopImmediatePropagation`
- handleEvent-object listeners (`{ handleEvent: fn }`)

Listener errors don't abort dispatch — caught and routed through
`console.error` to match Node's resilient behaviour.
