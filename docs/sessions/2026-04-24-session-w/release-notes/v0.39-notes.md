# ionpower-node 0.39 — small refinements

Three small refinements.

## `http.Agent` stub

```js
const http = require('http');
const agent = new http.Agent({ keepAlive: true, maxSockets: 10 });
http.globalAgent;                     // default instance
```

Node's `Agent` pools TCP connections across requests for keep-alive.
Our sync-curl HTTP path can't pool and our async path opens a socket
per request, so the Agent is effectively a no-op — but it exposes
the expected shape (`keepAlive`, `maxSockets`, `.getName(opts)`,
`.destroy()`, etc.) so libraries constructing one don't TypeError.

## `crypto.hash` one-shot

Node 20+ one-shot hash API:

```js
const crypto = require('crypto');
crypto.hash('sha256', 'abc');              // hex string (default)
crypto.hash('sha256', 'abc', 'base64');    // base64
crypto.hash('sha256', 'abc', 'buffer');    // Buffer
```

Verified against FIPS vectors for SHA-256, SHA-1, and MD5.

## `AbortSignal.any` dispatches its own `'abort'` event

Previously `AbortSignal.any([a, b])` updated the combined signal's
`.aborted` and `.reason` when any source aborted, but didn't fire
the combined signal's own `'abort'` listeners. Fixed — now dispatches
to both `addEventListener('abort', fn)` and `.onabort`, with
guaranteed fire-once semantics.
