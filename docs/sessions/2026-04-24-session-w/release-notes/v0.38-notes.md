# ionpower-node 0.38 — `Buffer.indexOf` strings + library hunt wave 8

Two things.

## `Buffer.indexOf` now accepts strings / Buffers

Previously `Buffer.indexOf` inherited `Uint8Array.prototype.indexOf` —
strict-identity byte-value search only. Anything else returned `-1`,
forcing callers (WebSocket handshake, HTTP parser) to route through
`buf.toString('latin1').indexOf(...)`.

```js
const buf = Buffer.from("hello\r\n\r\nworld");

buf.indexOf("\r\n\r\n");          // 5   — string needle
buf.indexOf(Buffer.from([0x72, 0x6c]));  // 11 — Buffer needle
buf.indexOf(111);                // 4   — byte needle ('o')
buf.includes("world");           // true

buf.indexOf("世", 0, "utf8");     // UTF-8 encoded needle
```

Optional 3rd arg is the encoding for the string form (default `utf8`).
