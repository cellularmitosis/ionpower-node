# ionpower-node 0.42 — worker_threads / inspector / tty stubs + library hunt wave 11

Three require-core additions. Stub-shaped since ionpower-node has no
threads, no V8 inspector, and no real terminal control — but the
shape is enough for libraries that feature-detect or conditionally
branch.

## `require('worker_threads')`

```js
const { isMainThread, Worker } = require('worker_threads');
if (!isMainThread) { /* ... */ }   // never taken — isMainThread is always true
new Worker('...');                 // throws "not supported"
```

- `isMainThread: true`, `threadId: 0`, `parentPort: null`.
- `Worker`, `MessageChannel`, `MessagePort`, `BroadcastChannel`
  constructors all throw on use.
- `getEnvironmentData` / `setEnvironmentData` / `markAsUntransferable`
  / `receiveMessageOnPort` are no-ops.

## `require('inspector')`

- `Session` throws.
- `open` / `close` / `waitForDebugger` are no-ops; `url()` returns
  undefined.
- Enough for logger libs that sniff for the module's presence.

## `require('tty')`

Promoted from anaemic stub to a real `WriteStream` / `ReadStream`
with `.isTTY`, `.columns = 80`, `.rows = 24` set in the constructor,
plus `getColorDepth() / hasColors() / getWindowSize()`. Removed the
late duplicate registration that was overwriting the full impl.
