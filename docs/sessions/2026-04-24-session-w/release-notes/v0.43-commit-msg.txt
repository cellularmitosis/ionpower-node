v0.43: poll-based fs.watch + library hunt wave 12

fs.watch + watchFile / unwatchFile + FSWatcher class, all poll-based:

  const w = fs.watch('/tmp/file', { interval: 100 }, (ev, name) => {
      console.log(ev, name);          // 'change' | 'rename'
  });
  w.close();

  fs.watchFile('/tmp/file', (cur, prev) => { ... });
  fs.unwatchFile('/tmp/file');

Node uses FSEvents / inotify; we stat() on a timer (default 5007 ms,
overridable via `interval` option) and emit 'change' on
mtime-or-size deltas, 'rename' when the file appears/disappears.

Good enough for hot-reload loops.  Consumers of fs.watch that need
millisecond-grain native notification still miss out — the API
shape matches, the fidelity doesn't.
