# ionpower-node 0.48 — `events.on` async iterator

`events.on(emitter, name, options?)` returns a Node-shaped async
iterator that yields each event payload as a Promise.

```js
const events = require('events');

const ee = new events.EventEmitter();
const iter = events.on(ee, 'data');

ee.emit('data', 'alpha');
ee.emit('data', 'bravo');

iter.next().then(r => { /* r.value === ['alpha'] */ });
iter.next().then(r => { /* r.value === ['bravo'] */ });
iter.return();      // stop iteration, remove listeners
```

Built by hand since SM45 has no async generators. The iterator
exposes `.next()` / `.return()` / `.throw()` returning Promises,
plus `[Symbol.asyncIterator]` returning self — so once async
iteration syntax (`for await`) lands in the engine it just works.

## Cancellation

```js
const c = new AbortController();
const iter = events.on(ee, 'x', { signal: c.signal });
c.abort();           // pending iter.next() rejects with AbortError
```

## Error event propagation

When the emitter fires `'error'`, all pending `.next()` calls reject
with that error — matching Node's behaviour.

## Verified

Three smoke assertions on G3 / G4 / G5:
- 3 emitted values are yielded in order, then `.return()` stops cleanly.
- AbortSignal cancellation rejects pending `.next()`.
- An `'error'` event rejects pending `.next()` with the error.
