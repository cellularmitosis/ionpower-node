# ionpower-node 0.43 — poll-based `fs.watch` + library hunt wave 12

## `fs.watch` / `fs.watchFile` / `fs.unwatchFile` / `fs.FSWatcher`

```js
const w = fs.watch('/tmp/file', { interval: 100 }, (event, filename) => {
    console.log(event, filename);    // 'change' | 'rename'
});
// ... later
w.close();

fs.watchFile('/tmp/file', (curr, prev) => { /* on stat delta */ });
fs.unwatchFile('/tmp/file');
```

Implementation is poll-based: Node uses FSEvents (macOS) or inotify
(Linux); we `stat()` on a timer (default 5007 ms, overridable via
`interval`) and emit `'change'` on mtime-or-size deltas, `'rename'`
when the file appears or disappears. The shape matches Node
(`'change'`/`'rename'` events, `.close()`, EventEmitter) — the fidelity
does not.

Good enough for hot-reload loops and dev-tool file watchers. Anything
that needs sub-interval latency still misses out.

`watchFile` / `unwatchFile` use a per-path map so multiple listeners
share a single poller.
