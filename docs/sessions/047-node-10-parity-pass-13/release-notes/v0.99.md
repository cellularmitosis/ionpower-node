# ionpower-node v0.99

**Headline: `npm install express@5 && node server.js` works
end-to-end on a real iBook G3.**

The 13th Node-10 parity pass started as a survey ("which top-N npm
packages load on v0.98?") and turned into a three-bug bug-find tour
that, together, cleared the path for `express@5` to boot a real
HTTP server with no source changes. 8 of 10 surveyed packages load
clean out of the box; the surveyed failures pointed straight at the
fixes that shipped here.

## Survey of popular Node-10-era npm packages

8 of 10 work clean against the live registry on G3:

|              |              |              |              |
|--------------|--------------|--------------|--------------|
| ✅ lodash    | ✅ debug     | ✅ dotenv    | ✅ bluebird  |
| ✅ chalk@4   | ✅ commander | ✅ winston   | ✅ joi       |
| ❌ axios     | ❌ node-fetch |             |              |

Of the 8 passing: `lodash`/`debug`/`dotenv`/`bluebird` load directly;
`chalk@4`/`commander`/`winston`/`joi` exercise the Babel
parse-failure fallback (object spread, destructuring patterns, async
helpers).

- `axios` — `require('axios')` reaches the real gap: `require('http2')`
  from `axios.cjs:37`. Three resolver/Babel bugs surfaced on the way
  in (now fixed; see below). For an axios that works today, pin
  `axios@^0.27` — the last pre-http2 line.
- `node-fetch@3` — ESM-only; uses async iterators + private class
  fields beyond what `@babel/preset-env` with `targets: { ie: 11 }`
  lowers. ionpower-node already exposes a built-in `fetch()` since
  v0.96; use that.

Full per-package logs and the survey script:
[`docs/sessions/047-node-10-parity-pass-13/`](https://github.com/cellularmitosis/ionpower-node/tree/v0.99/docs/sessions/047-node-10-parity-pass-13/).

## Fixes

### Resolver — read the whole `package.json` for the `"main"` field
([`src/node_compat/require.cpp`](https://github.com/cellularmitosis/ionpower-node/blob/v0.99/src/node_compat/require.cpp))

`FindTopLevelMainKey` used a fixed 4 KB stack buffer. axios@1.16.1's
`package.json` is 7.4 KB and puts `"main": "./dist/node/axios.cjs"`
past byte 4095 — the resolver missed it and fell through to
`index.js` (the ESM source tree). Now stats the file and reads up to
1 MB. Smoke at
[`test/package_main_large_smoke.js`](https://github.com/cellularmitosis/ionpower-node/blob/v0.99/test/package_main_large_smoke.js).

### Babel discovery — also probe `<exeDir>/test/vendor/babel.js`
([`src/node_compat/globals.cpp`](https://github.com/cellularmitosis/ionpower-node/blob/v0.99/src/node_compat/globals.cpp))

The Babel-fallback loader looked at cwd-relative paths and the
tarball-install path (`<exeDir>/../share/ionpower-node/vendor/babel.js`),
but missed the dev-tree case (`<exeDir>/test/vendor/babel.js`). When
running ionpower-node out of its own source tree with cwd somewhere
else, Babel was silently unavailable and ES2018+ packages would fail
with parse errors. Now adds `<exeDir>/test/vendor/babel.js` and
`<exeDir>/vendor/babel.js` to the candidate list.

### Top-level-await heuristic — CJS guard
([`src/node_compat/globals.cpp`](https://github.com/cellularmitosis/ionpower-node/blob/v0.99/src/node_compat/globals.cpp))

`_looksLikeTopLevelAwait` brace-counts to decide whether to wrap the
source in `(async function () { … })()`. Template literals with
`${…}` substitutions made the counter go negative (the `{`/`}` from
the substitution land outside the string-stripping pass), so an
`await` inside an `async function*` looked top-level. The IIFE wrap
then ate the synchronous `module.exports = …`. Fix: short-circuit
the heuristic to `false` when the source contains `module.exports`
or `exports.X = …`. Node forbids TLA in CJS, so the guard is safe.
Smoke at
[`test/babel_tla_cjs_guard_smoke.js`](https://github.com/cellularmitosis/ionpower-node/blob/v0.99/test/babel_tla_cjs_guard_smoke.js).

### Babel preset-env: drop `loose: true` (fixes `[...Set]` regression)
([`src/node_compat/globals.cpp`](https://github.com/cellularmitosis/ionpower-node/blob/v0.99/src/node_compat/globals.cpp))

Surfaced by re-running the libs smoke on G3 against a freshly-wiped
disk cache. `[...new Set(arr)]` from `test/vendor/array-uniq.js`
lowered to `[].concat(new Set(arr))` under `loose: true`, which
wraps the Set in a one-element array instead of iterating its
values — so `array-uniq([1,2,2,3,3,3])` returned `[{}]` (Set
JSON.stringify's as `{}`) instead of `[1,2,3]`. Latent since v0.84;
G4/G5 caches predated v0.84 and held the correct non-loose
transform, masking it. Dropped loose mode; preset-env now emits the
iterator-protocol-aware `_toConsumableArray(x)` helper that walks
Sets/Maps/generators via `Array.from`. Slightly larger output,
correct semantics. Smoke at
[`test/babel_spread_iterable_smoke.js`](https://github.com/cellularmitosis/ionpower-node/blob/v0.99/test/babel_spread_iterable_smoke.js).

## Verification

- All 21 core smokes pass on G3 — incl. three new ones
  (`package_main_large_smoke.js`, `babel_tla_cjs_guard_smoke.js`,
  `babel_spread_iterable_smoke.js`).
- All 495 / 0 libs smokes pass on G3 against a freshly-wiped Babel
  disk cache — no regressions from v0.98.
- **`npm install express@5 && node server.js` end-to-end on G3.**
  Server boots in ~2 min (cold Babel cache; <1s after); responds
  200 OK on `/` and `/json`. Build log:
  [`docs/sessions/047-node-10-parity-pass-13/build-logs/express5-client.log`](https://github.com/cellularmitosis/ionpower-node/blob/v0.99/docs/sessions/047-node-10-parity-pass-13/build-logs/express5-client.log).

## Carryover

- `require('http2')` is unimplemented — blocks `axios@1.x`, `got`,
  several others. Either ship http2 or add a throwing stub.
- One cosmetic prototype-mutation warning at express@4 / express@5
  load.
