Monkey-patch validation: IM buffering fix unlocks `npm install <name>`.

Patch installed via /tmp/run-npm-patched.js (loaded before npm-cli.js
require), prepending these overrides to http.IncomingMessage.prototype:

  - emit('data', x): if !_imFlowing, push x onto _imBuf; else forward
    to origEmit.
  - emit('end'):     if !_imFlowing, set _imEndQueued; else forward.
  - on(ev, fn):      if ev === 'data' && !_imFlowing, set _imFlowing
                     and process.nextTick(drain).
  - pause():         _imFlowing = false.
  - resume():        if !_imFlowing, set _imFlowing and nextTick(drain).

Where drain() pops _imBuf chunks through origEmit('data', c), then
fires origEmit('end') if _imEndQueued.
