# ionpower-node 0.8 — the rounding-out release

Third-party libraries with passing smokes: **501 → 504**.
Assertions: **1186 → 1205**. Validated on G3 / G4 / G5.

This is the **Node-interface rounding-out** release. Where v0.6/v0.7
built out the event loop surface, v0.8 fills in the remaining utility
modules and lands a real `child_process` — the last big gap for a
lot of CLI-tool use cases.

## Runtime additions

- **`os` — full.** `type`, `release`, `version`, `endianness` (`BE`
  on PPC), `userInfo`, `networkInterfaces` (empty stub),
  `loadavg`/`freemem`/`totalmem`/`uptime`, `availableParallelism`,
  `constants.signals`/`errno`/`priority`, `devNull`. Was a partial
  stub before.
- **`util` — full.** `parseArgs`, `isDeepStrictEqual`,
  `stripVTControlCharacters`, `TextEncoder`/`TextDecoder` mirrors.
  Plus everything the previous release had.
- **`events` — polished.** `events.once(emitter, name)` returning a
  Promise; `prependListener`, `prependOnceListener`, `rawListeners`,
  `eventNames`, `off` alias. `events.getEventListeners`,
  `events.setMaxListeners`, `events.defaultMaxListeners` on the
  module exports.
- **`url` — full.** Legacy `parse(s, parseQS, slashesDenoteHost)`
  returns a real URL object (protocol/slashes/auth/host/hostname/
  port/pathname/search/query/hash). `format`, `resolve`,
  `fileURLToPath`, `pathToFileURL`. WHATWG `URL`/`URLSearchParams`
  still exposed.
- **`querystring` — full.** Custom `sep`/`eq`, array-valued keys,
  `escape`/`unescape`/`encode`/`decode`. `parse` auto-combines
  duplicate keys into arrays; `stringify` emits repeated `k=v`
  for array values.
- **`path` — polished.** `relative`, `normalize`, `parse`, `format`,
  `delimiter`. Added `path.posix` (self-alias) and `path.win32`
  (best-effort) so libraries that reach into the sub-namespaces
  load.
- **`crypto` — SHA-224 + randomInt.** SHA-224 shares the SHA-256
  core with a different IV and truncates to 28 bytes. RFC 4231
  HMAC-SHA224 vector verified. `crypto.randomInt(max)` /
  `crypto.randomInt(min, max)` using `randomBytes(4)`. `scrypt`/
  `scryptSync` stubs throw clearly.
- **`string_decoder` — partial UTF-8 buffering.** Previously any
  partial multibyte at the end of a `.write()` chunk was corrupted;
  now the decoder buffers up to 3 trailing bytes and flushes them
  on the next `.write()` or emits U+FFFD per leftover byte on
  `.end()`. Fixes split2/through2 byte-boundary corruption.
- **`child_process` — sync variants real.** New native module
  (`src/node_compat/child_process.cpp`, ~400 lines) implementing
  `execSync`, `spawnSync`, `execFileSync` via fork+exec+waitpid.
  Handles `cwd`, `input` (string or Buffer fed to stdin), `encoding`
  (returns string instead of Buffer). `spawnSync` returns `{pid,
  status, signal, stdout, stderr}`. `execSync` throws with
  `.status`/`.stdout`/`.stderr` on non-zero exit. Async `spawn`/
  `exec`/`fork` still throw (no event loop yet).
- **`zlib` — stub with full constants.** Module exports
  `createGzip`/`createGunzip`/`createDeflate`/`createInflate` plus
  raw variants and brotli; `gzipSync`/`gunzipSync`/etc all throw
  a clear "not implemented" error. Full `zlib.constants.*` so
  library probes that gate on constant presence succeed.
  (Real implementation would need RFC 1950/1951 inflate/deflate.)
- **`process.stdin` — Readable.** `.fd = 0`, `.isTTY`, `.on('data')`
  / `.on('end')`, `.pause()` / `.resume()` / `.setEncoding()` /
  `.setRawMode()`. First `'data'` listener triggers a synchronous
  drain of `/dev/stdin` (via `fs.readFileSync`) and emits the whole
  buffer as one chunk, then `'end'`. Covers the `cat foo.txt |
  node` pattern; TTY stdin short-circuits out.

## Buffer.toString('utf8') is now lossy

Previously `new Uint8Array([0xe2, 0x82]).toString('utf8')` threw
`InternalError: buffer too small` because SpiderMonkey's strict
UTF-8 converter rejects partial sequences. Now falls back to the
lossy converter (emits U+FFFD for each invalid byte), matching
Node's behavior. `StringDecoder.end()` depends on this.

## Library additions

- `filter-obj` — object-filter by predicate or allowlist
- `is-relative-url` — inverse of `is-absolute-url`
- `titleize` — title-case a string

Library count 501 → 504. More importantly, many *existing* libraries
now exercise the new API paths (os userInfo, util parseArgs, events
once, child_process execSync, etc.) cleanly.

## Install

Each tarball installs to `/opt/ionpower-node-0.8/`. Depends on a
matching `/opt/mozjs-45-ionpower*` build per CPU (G3 / G4 / G5).

```
tar -C /opt -xzf ionpower-node-0.8-g5-ppc.tar.gz
/opt/ionpower-node-0.8/bin/node script.js
```

## Known limitations

- No SHA-512 (needs 64-bit emulation). No scrypt. Stubs throw.
- `zlib` compress/decompress throw. Constants present.
- Async `child_process` (spawn/exec/fork) still throws.
- `http`/`https`/`net`: sync only.
- No Intl.
