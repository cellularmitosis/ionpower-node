v0.40: util.styleText + library hunt wave 9

util.styleText (Node 21+):

  util.styleText('red', 'hi');
  util.styleText(['red', 'bold'], 'hi');
  util.styleText('red', 'hi', { validateStream: false });  // force ANSI

Styles: reset/bold/dim/italic/underline/blink/inverse/hidden/
strikethrough, plus 8 foreground colors (+ gray/grey) and their
bg* variants. Unknown names throw TypeError. Without an explicit
TTY/validateStream override, non-TTY output returns the plain
text (matches Node's default).
