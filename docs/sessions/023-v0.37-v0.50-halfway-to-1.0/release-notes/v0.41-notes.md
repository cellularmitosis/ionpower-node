# ionpower-node 0.41 — `vm` module + `module.isBuiltin` + library hunt wave 10

## `vm` module

Minimal subset — no real compartment isolation, but enough for the
"evaluate a small expression against a known-keys sandbox" pattern
that template engines and JSON-path probes use.

```js
const vm = require('vm');

vm.runInThisContext("1 + 2");                   // 3
vm.runInNewContext("x + y", { x: 10, y: 20 });  // 30

const script = new vm.Script("n * 2");
script.runInNewContext({ n: 21 });              // 42

const fn = vm.compileFunction("return a + b;", ["a", "b"]);
fn(2, 3);                                        // 5

const ctx = vm.createContext({ shared: 99 });
vm.runInContext("shared + 1", ctx);             // 100
```

`runInNewContext` parameterizes the sandbox keys as `Function()`
arguments and invokes the result with the sandbox values. Expression-
shaped code runs and returns its value; statement-shaped code runs
but only mutates the sandbox if it assigns back via its key name
(closure scope — no real contextification).

## `module.isBuiltin`

Node 18+ helper:

```js
const { isBuiltin } = require('module');
isBuiltin('fs');              // true
isBuiltin('node:fs');         // true (node: prefix stripped)
isBuiltin('does-not-exist');  // false
```
