# ionpower-node 0.37 — WebSocket (RFC 6455) client + server

Adds a browser-style `WebSocket` global plus a Node-style `ws`
module, both built on top of our existing `net.Socket`.

## What's new

### Client (browser-style)

```js
const ws = new WebSocket("ws://host:port/path");

ws.onopen    = () => ws.send("hello");
ws.onmessage = (ev) => console.log("got:", ev.data);
ws.onclose   = (ev)  => console.log("closed", ev.code, ev.reason);
ws.onerror   = (err) => console.log("err", err.message);

ws.send(Buffer.from([1, 2, 3]));   // binary frame
ws.close(1000, "done");
```

### Server (Node-style)

```js
const { WebSocketServer } = require("ws");
const server = new WebSocketServer({ port: 0, host: "127.0.0.1" });

server.on("connection", (client) => {
    client.on("message", (data, isBinary) => {
        client.send(data);                         // echo
    });
});
```

`server.on('listening', () => server.address())` returns the bound
port — passing `port: 0` picks an ephemeral one.

## Covers

- HTTP/1.1 upgrade handshake with `Sec-WebSocket-Key` / `-Accept`
  validation (SHA-1 + RFC magic + base64).
- Frame encode/decode with all three length forms (inline 7-bit,
  16-bit, 64-bit). Client frames are masked per spec with a
  4-byte random mask.
- Text (`0x1`) and binary (`0x2`) frames — text emits a string,
  binary emits a `Uint8Array`.
- Control frames: `ping` (`0x9`) auto-responds with `pong` (`0xA`);
  `close` (`0x8`) echoes back and shuts down cleanly.
- `readyState` enum (CONNECTING / OPEN / CLOSING / CLOSED).

## Does not yet do

- `wss://` (TLS) — no native TLS library.
- `permessage-deflate` extension.
- Fragmentation across multiple frames.

## Incidental fix

Our native `Buffer.indexOf("literal string")` returns `-1` — inherited
from `Array.prototype.indexOf`'s strict-identity behaviour. Workaround
in the handshake parser is `self._buffer.toString('latin1').indexOf(...)`.
Several other sites in `globals.cpp` already route through `toString`
first, so this is a known limitation; a future release will fix
`Buffer.indexOf` to accept strings natively.

## Verified

Text + binary + close round-trip between an in-process server and
client; `onopen` / `onmessage` / `onclose` all fire on both sides.
