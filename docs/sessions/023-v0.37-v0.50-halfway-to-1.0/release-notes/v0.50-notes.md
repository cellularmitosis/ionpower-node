## Where we are at v0.50

**28 releases shipped this session** (v0.23 → v0.50). Today's
session covers nearly every Node-shaped surface a typical
JavaScript library expects:

- **Crypto**: full symmetric (AES CBC/CTR/GCM/KW + HMAC + SHA family
  + PBKDF2 + HKDF + scrypt) plus **Ed25519** + **X25519 ECDH** plus
  nacl box / secretbox.
- **Network**: TCP (`net`), UDP (`dgram`), HTTP/HTTPS, WebSocket
  (RFC 6455 client + server).
- **Streams**: WHATWG ReadableStream / WritableStream / TransformStream.
- **Web APIs**: `fetch`, `EventTarget`/`Event`/`CustomEvent`,
  `performance`, `AbortController`/`AbortSignal`, `URL`, `TextEncoder`/
  `TextDecoder`, `crypto.subtle`.
- **Test runner**: `node:test` minimal TAP runner.
- **Module surface**: `vm`, `readline`, `perf_hooks`, `fs.watch` /
  `fs.cp` / `fs.rm`, `module.createRequire` / `isBuiltin`,
  `worker_threads` / `inspector` / `tty` stubs.
- **Promise variants**: `fs.promises`, `dns.promises`,
  `timers/promises`.
- **Async iteration**: `events.on(emitter, name)` returns an async
  iterator (built by hand — no async generator support).
- **648+ libraries** with passing smoke tests, **1675+** assertions
  across **399** smoke files.

## Still missing

- RSA / ECDSA (NIST P-256 etc.) — needs bignum + curve math.
- TLS — needs a native lib.
- Async generators / `for await` — engine-level (SM45).
- Real worker threads — POSIX threads not viable here.
