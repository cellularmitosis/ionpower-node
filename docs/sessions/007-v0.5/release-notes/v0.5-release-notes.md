# ionpower-node 0.5

Fifth tagged release. Follows [v0.4](https://github.com/cellularmitosis/ionpower-node/releases/tag/v0.4).

Main focus: **runtime hardening** — MD5 joined the inline crypto
hash set, Buffer.isEncoding landed, and another 40 libraries
(v0.4: 340 → v0.5: 380) came in behind them, largely via the
vendor-path resolver built up in v0.4.

## What's new since v0.4

### Runtime

- **`crypto.createHash('md5')`** — full RFC 1321 reference
  implementation in globals.cpp. Verified against the standard
  test vectors (`""` / `"abc"` / `"hello world"` / the quick
  brown fox). Hash() now accepts 'md5' / 'sha256' (+ case
  variants) and rejects others clearly.
- **`Buffer.isEncoding`** — returns true for
  utf8/ascii/binary/base64/base64url/hex/latin1/utf16le/ucs2.
  buffer-from and similar libraries gate on this.
- **`Uint8Array.isBuffer`** — stamped onto Uint8Array itself
  since our Buffer shares Uint8Array.prototype; is-buffer legacy
  calls `obj.constructor.isBuffer(obj)` and resolves correctly now.

### Libraries: **340 → 380** (+40)

The vendor resolver from v0.4 did most of the heavy lifting —
these mostly bare-require each other and wire up cleanly.

**Chalk-class / text pipeline**:
- camel-case, constant-case, param-case, dot-case, pascal-case
  (the atomic @change-case-org set with its tslib + no-case +
  upper-case chain — validates the resolver on a 4-deep
  dependency walk)
- format-file-size, pad-left, pad-right, mixin-deep,
  is-negative-zero, md5-hex

**URL / HTTP**:
- valid-url, property-expr, filename-reserved-regex, toidentifier
- url-template, url-join, detect-newline

**Utilities**:
- is-buffer, to-buffer, list-to-array, once, wrappy,
  strict-uri-encode, decode-uri-component, isarray
- make-error, prr, mnemonist/set
- throttleit, lodash.throttle, lodash.debounce (load-shape only)

**Core-module-like**:
- randombytes, ieee754, buffer-from, set-blocking, require-directory

**Search / format**:
- fuzzball, xml-name-validator, cidr-regex, text-hex

## Tarballs

    sudo tar -xzf ionpower-node-0.5-gN-ppc.tar.gz -C /opt

Then:

    /opt/ionpower-node-0.5/bin/node <script.js>

Expects the matching `/opt/mozjs-45-ionpower-g{3,4,5}/` on the
target host.

## Known limitations

Unchanged from v0.4:
- `stream` is a pass-through stub. tape parked.
- `Intl` missing (SM45 `--without-intl-api`).
- `wrap-ansi`'s ANSI-aware branch uses ES2018 named capture groups.
- No `fetch` / `AbortController` / real async `fs` / `http` /
  `net` — needs an event loop.
