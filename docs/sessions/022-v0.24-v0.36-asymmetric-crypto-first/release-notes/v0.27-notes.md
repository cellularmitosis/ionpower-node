# ionpower-node 0.27 — library hunt wave 5

Seven more vendored libraries brought under smoke coverage.  Most
were already sitting in `test/vendor/` untested; wave 5 adds the
smoke script that exercises them.

## New smokes

| Library | Shape verified |
|---|---|
| `escape-html` | `<script>...</script>` → `&lt;script&gt;...&lt;/script&gt;` round-trip |
| `escape-string-regexp` | ESM default export; escapes regex metachars (`.`, `*`, etc.) |
| `is-plain-object` | Plain object vs Array / Date / null discrimination |
| `mri` | Tiny arg parser; `--foo 1 -b hi positional` → `{ foo:1, b:'hi', _:['positional'] }` |
| `kleur` | Terminal colors; `.red(str)` returns a string containing the input |
| `dayjs` (minified) | `dayjs('2024-01-15').add(5,'day').format('YYYY-MM-DD')` = '2024-01-20' |
| `nanoid/non-secure` | ESM; default 21-char id, custom size, uniqueness |

## Totals

- Libraries with smoke coverage: **585 → 592+**
- Assertions: **1410+** across **376** smoke files.

```
tar -C /opt -xzf ionpower-node-0.27-g5-ppc.tar.gz
/opt/ionpower-node-0.27/bin/node script.js
```
