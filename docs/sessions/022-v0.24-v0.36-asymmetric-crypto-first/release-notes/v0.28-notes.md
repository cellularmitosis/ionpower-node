# ionpower-node 0.28 — ES2022 / ES2023 small-API polyfills

SpiderMonkey 45 predates most of the "library authors assume this
exists" APIs from the last few years. This release adds trivial
polyfills for the common missing surface, all gated by `typeof X ===
'undefined'` so a future mozjs bump brings native impls through
cleanly.

## What's new

### Object / Array / String additions

- `Object.hasOwn(obj, key)` — more reliable `hasOwnProperty`
- `Array.prototype.at(i)` — negative indexing
- `Array.prototype.findLast(fn)` / `findLastIndex(fn)` — reverse scan
- `Array.prototype.toSorted(cmp)` — returns sorted copy
- `Array.prototype.toReversed()` — returns reversed copy
- `Array.prototype.toSpliced(start, deleteCount, ...items)` — returns spliced copy
- `Array.prototype.with(i, v)` — returns copy with index replaced
- `String.prototype.at(i)` — negative indexing
- `String.prototype.replaceAll(search, replace)` — global replace (string or `/g` regex)

### Error / Promise

- `AggregateError` — Error subclass carrying `.errors` array
- `Promise.any(iter)` — resolves with first fulfilled; else rejects with `AggregateError`

### structuredClone

```js
const copy = structuredClone({ a: 1, b: [2, 3], when: new Date() });
```

Supports: plain objects, arrays, `Date`, `RegExp`, `Map`, `Set`,
`Buffer`. Other types (TypedArray, Blob, ArrayBuffer, class instances)
fall through to plain-object copy. Does **not** detect cycles — don't
clone self-referential graphs.
