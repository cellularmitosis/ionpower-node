# ionpower-node 0.29 — dgram (UDP)

Adds the Node `dgram` core module for UDP sockets.

## What's new

### Native primitives on `__net_native__`

- `sendto(fd, bufOrString, host, port)` → bytes sent (or -1 on
  EAGAIN).
- `recvfrom(fd, maxLen=65536)` → `{ data: Uint8Array, address, port,
  size }` or `null` on EAGAIN.

### `dgram` module

```js
const dgram = require('dgram');

const server = dgram.createSocket('udp4');
server.on('listening', () => console.log('bound', server.address()));
server.on('message', (msg, rinfo) => {
    console.log('got', msg.toString(), 'from', rinfo.address, rinfo.port);
    server.send('pong', rinfo.port, rinfo.address);
});
server.bind(0, '127.0.0.1');

const client = dgram.createSocket('udp4');
client.on('message', (msg) => {
    console.log('reply:', msg.toString());
    client.close();
});
client.send('ping', server.address().port, '127.0.0.1');
```

Supports:
- `dgram.createSocket('udp4')` and `new dgram.Socket({ type })`
- `bind(port, address, cb)` / `bind(opts, cb)` / `bind(cb)` —
  ephemeral port when omitted.
- `send(buf, port, address, cb)` and the legacy 6-arg
  `send(buf, offset, length, port, address, cb)` shape.
- `address()` returns `{ address, family: 'IPv4', port }`.
- `close(cb)`.
- Events: `'listening'`, `'message'`, `'error'`, `'close'`.
- Buffer + string payloads.
- Auto-bind to ephemeral port on first `send()` if not yet bound.

## Not yet

- Multicast (`addMembership` / `dropMembership`)
- `setBroadcast` (stubbed)
- `setTTL` / `setMulticastTTL`
