# ionpower-node 0.35 — `assert.rejects` + library hunt wave 7

Adds the Promise-aware assertion helpers that modern test suites
use, plus another batch of vendored libraries.

## What's new

### `assert.rejects` / `doesNotReject` / `match` / `doesNotMatch`

```js
const assert = require("assert");

// Resolves when the promise rejects; error shape is optional.
await assert.rejects(fetch("http://bad"));
await assert.rejects(fetch("http://bad"), TypeError);
await assert.rejects(fetch("http://bad"), /ECONNREFUSED/);
await assert.rejects(fetch("http://bad"), { code: "ECONNREFUSED" });

// Resolves if the promise fulfills; throws otherwise.
await assert.doesNotReject(fetch("http://good"));

// Regex on strings.
assert.match("hello world", /world/);
assert.doesNotMatch("hello", /xyz/);
```

`thenable` accepts either a Promise directly or a `() => Promise`
function (matches Node's signature). Shape objects are checked
key-by-key against the error; RegExp values match via `.test(String(val))`.

Eight more vendored libraries under smoke coverage:

| Library | Shape |
|---|---|
| `eventemitter3` | Single-file 336-line drop-in `EventEmitter`. |
| `mitt` | 1-line minified nanopubsub. |
| `tiny-emitter` | 67-line emitter. |
| `is-number` | Schlinkert's numeric-string predicate. |
| `hexoid` | Fast hex id generator (returns a generator function). |
| `jsesc` | JS string escape (escapes non-ASCII). |
| `js-tokens` | JS tokenizer (loaded only — syntax varies widely). |
| `seedrandom` | Deterministic PRNG (kept the older single-file v0.19-era copy — the upstream current requires `./lib/alea` submodules we don't vendor). |
