# ionpower-node 0.25 — module core (createRequire + builtinModules)

Adds the Node 12+ `module` core surface. Dual-mode (ESM + CJS)
packages use this to get a `require()` bound to the current file.

## What's new

### `module.createRequire(filename | file:// URL)`

```js
const { createRequire } = require("module");
const localRequire = createRequire(__filename);
// or from an ESM file's import.meta.url equivalent:
const r = createRequire("file:///absolute/path/to/file.js");

const fs = localRequire("fs");
const lib = localRequire("./vendor/crc32.js");
localRequire.resolve("./vendor/crc32.js");
```

Accepts either an absolute path or a `file://`-prefixed URL string.
The returned `require` is rooted at the `dirname` of the passed
filename, so relative specifiers resolve correctly from the caller's
location.

Built on top of the existing `__make_require__(dir)` primitive — just
peels the dirname off the filename and hands it over.

### `module.builtinModules`

An array listing the core module names we seed in `__require_cache__`:
`['fs', 'path', 'events', 'util', 'child_process', 'os', 'crypto',
'buffer', 'string_decoder', 'assert', 'stream', 'timers',
'querystring', 'readable-stream', 'inherits', 'supports-color',
'has-ansi', 'module']`.
