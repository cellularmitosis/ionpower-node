# ionpower-node 0.33 — tweetnacl via `require('tweetnacl')`

Makes tweetnacl a first-class, always-ready require target instead
of v0.30's internal helper. Users get a fully-wired `nacl` without
needing to call `setPRNG` themselves.

## What's new

```js
const nacl = require('tweetnacl');

// Symmetric authenticated encryption (XSalsa20-Poly1305):
const key   = nacl.randomBytes(32);
const nonce = nacl.randomBytes(24);
const ct    = nacl.secretbox(msg, nonce, key);
const pt    = nacl.secretbox.open(ct, nonce, key);   // null on tamper

// Asymmetric authenticated encryption (curve25519 + XSalsa20-Poly1305):
const alice = nacl.box.keyPair();
const bob   = nacl.box.keyPair();
const ctBox = nacl.box(msg, nonce, bob.publicKey, alice.secretKey);
const ptBox = nacl.box.open(ctBox, nonce, alice.publicKey, bob.secretKey);

// Hashing (SHA-512 built-in):
const h = nacl.hash(new Uint8Array([0x61, 0x62, 0x63]));  // 64 bytes

// Detached Ed25519 sign/verify (same as v0.30/31):
const kp  = nacl.sign.keyPair();
const sig = nacl.sign.detached(msg, kp.secretKey);
nacl.sign.detached.verify(msg, sig, kp.publicKey);        // true
```

## How it works

The wrapped `__make_require__` now short-circuits `require('tweetnacl')`
to the internal `_naclLoad()`, which:

1. Resolves `tweetnacl.js` by walking the vendor directories
   (`test/vendor/`, `<cwd>/vendor/`, and `<exeDir>/../share/ionpower-node/
   vendor/`) itself — avoiding recursion through the wrapped require.
2. Returns the library with `setPRNG()` wired to
   `crypto.getRandomValues`, so `nacl.randomBytes(n)` actually
   produces random bytes (previously the stub threw).

## Verified

Four smoke assertions on G3 / G4 / G5:
- `nacl.secretbox` round-trip + tamper-rejection
- `nacl.box` round-trip + wrong-sender rejection
- `nacl.hash` (FIPS "abc" prefix)
- `nacl.sign.detached` round-trip
