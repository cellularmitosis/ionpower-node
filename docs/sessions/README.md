# Session archive

One directory per session. Each contains a narrative (`summary.md`
for legacy sessions, `notes.md` for newer ones) and, where the
session built/shipped releases, `build-logs/` per-host build +
smoke logs and `release-notes/` copies of GitHub release prose.

Legacy sessions (April 21–24, 2026) used a monotonic-letter
identifier within a date (`session-a`, `session-b`, …); newer
sessions use a within-date counter matching the convention in
sibling projects (`session-1`, `session-2`, …).
