# ionpower-node 0.6

**The big event-loop release.** v0.5's runtime gave you a real
WHATWG URL, util.promisify, vendor-path require resolver, MD5
inline. v0.6 adds the pieces those shims really wanted: a proper
**timer queue**, **real Stream classes**, **async fs**, and
**SHA-1 / PBKDF2 / HMAC family**. Library count moves from 380 → 453.

## What's new since v0.5

### Runtime (the big six)

**Timer queue + event-loop drain.** `setTimeout` / `setImmediate` /
`setInterval` no longer fire synchronously — they enqueue into
`__timer_queue__` (stamped on the global). After the entry script
returns, `main.cpp` calls `__drain_timers__()` which pops the
earliest-fireAt record, invokes it, re-queues intervals, and loops
until the queue is empty. Second drain pass runs after 'exit'
handlers so hooks that schedule more timers don't get dropped.
Ordering matches Node; absolute wallclock delays don't.

**Real Stream classes.** `stream.Readable`/`Writable`/`Duplex`/
`Transform`/`PassThrough` with proper
`_read`/`_write`/`push`/`pipe`/buffering + `stream.pipeline()` +
`stream.finished()`. Implementations handle backpressure nominally
(collapses to always-drained under sync); pipe wires `data`/`end`/
`error` forwarding; Transform has `_transform` + `_flush`.

**Async fs.** Every `fs.*Sync` has a callback twin that fires via
`setImmediate`. `fs.promises.*` is the Promise wrap. `fs.constants`
covers `F_OK`/`R_OK`/`W_OK`/`X_OK`. `fs.access` / `accessSync` /
`realpath` / `realpathSync` / `exists` round it out.

**Crypto expansion.** Added inline SHA-1 (RFC 3174). HMAC generalized
to md5 / sha1 / sha256. PBKDF2 implemented on top.
RFC vectors verified: FIPS 180-1 (SHA-1), RFC 2104 (HMAC-MD5),
RFC 2202 (HMAC-SHA1), RFC 6070 (PBKDF2).

**Seeded core-module aliases.** `readable-stream` → built-in
`stream`. `inherits` → `util.inherits`. Libraries that bare-require
these in the stream tree now resolve cleanly.

### Libraries: **380 → 453** (+73)

Notable unblocks thanks to the new surface:
- **Stream ecosystem**: through, through2, split2, concat-stream,
  end-of-stream, pump, duplexer, from2
- **CSV / NDJSON**: csv-parser, ndjson
- **Crypto**: bcryptjs (real password-hash round-trip), md5-hex
- **lodash subpaths**: merge, pick, omit, uniq, groupby, sortby,
  clonedeep, isequal
- **Express ecosystem**: etag, fresh, basic-auth, destroy,
  encodeurl, parseurl, on-finished, ee-first, range-parser,
  methods, statuses, finalhandler (via a `debug` stub)
- **URL / URI**: uri-js, urlpattern-polyfill, url-template,
  cidr-regex, valid-url
- **Data**: diff-match-patch, tinycolor2, iban, rrule, xmldoc,
  fuzzball, mime-types, Mime, color-hash, frb-tree, heap-lib
- **Tiny utils**: type-is, media-typer, forwarded, vary,
  cookie-parser, defu, iterall, expand-template, tinyqueue,
  any-base, base32, crypt, has, tiny many more

### Composition demo

`demos/log-scan/app.js` — scans an Apache-ish log file, groups
by status-code class, writes a colored table + JSON sidecar.
Chains eight pieces of the new surface: stream.Transform + split2
+ fs.writeFile (async) + crypto.createHash('sha1') + chalk +
hash-sum + text-table + pretty-ms.

## Tarballs

    sudo tar -xzf ionpower-node-0.6-gN-ppc.tar.gz -C /opt

Then:

    /opt/ionpower-node-0.6/bin/node <script.js>

Expects the matching `/opt/mozjs-45-ionpower-g{3,4,5}/` on the
target host.

## Known limitations

- No wallclock-delay in timers — ordering is correct, but
  `setTimeout(fn, 1000)` fires the moment the entry script returns,
  not a second later.
- Pipe's auto-resume drains the upstream during `pipe()` 's
  listener-setup, which means `src.pipe(dst)` chains may deliver
  data but the pipe's own `end`-handler doesn't attach in time.
  Use direct `.write()` / `.end()` on the destination for deterministic
  consumption (see `demos/log-scan/app.js`). Real fix: defer resume.
- **tape** still parked (needs `process.stdout` as a proper
  Writable + 8 sibling-file vendor).
- `Intl` still missing — SM45 built `--without-intl-api`.
- `http`/`https`/`net`: no async surface; sync-GET only.
- `process.stdin`: not yet wired.
