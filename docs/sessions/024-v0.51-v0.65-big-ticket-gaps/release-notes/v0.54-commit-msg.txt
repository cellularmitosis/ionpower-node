v0.54: stream.Readable.from + Readable.toArray

Two Node 12+ / 18+ stream helpers:

  stream.Readable.from(input)     // input: array, string, Buffer,
                                  // Uint8Array, sync iterator, or
                                  // Symbol.iterator-bearing object

  readable.toArray()              // Promise<Array> — drains all chunks

Readable.from defers each push via setImmediate so the caller has
a tick to attach 'end' / 'data' listeners before emissions race
ahead. Without that defer, sync push-and-emit beats user
on('end', fn) registration.

toArray returns a Promise that resolves with the array of all
emitted chunks; rejects on 'error'.

Verified end-to-end:
- Readable.from([1,2,3]).toArray() -> [1,2,3]
- Readable.from('hello') emits one 'data' event with the string
- Readable.from(Buffer) emits one Buffer chunk
- Readable.from(array) | PassThrough -> toArray returns the same array

Library count: 651+ (unchanged). Assertions 1696 -> 1700+ across
403 smoke files.
