# ionpower-node 0.52 — `BroadcastChannel` + library hunt wave 18

## `BroadcastChannel`

In-process publish/subscribe. Real Node delivers across worker
threads + processes; we have neither, so every channel with the
same name in the **same process** sees each other's posts. Useful
for in-process pub/sub.

```js
const a = new BroadcastChannel('chan');
const b = new BroadcastChannel('chan');

b.onmessage = (ev) => console.log('got:', ev.data);
a.postMessage('hello');           // b receives 'hello' on next microtask
b.close();                        // stop receiving
```

Spec-compliant where it matters:

- Sender does **not** receive its own posts.
- Posts are dispatched on a microtask (not synchronous).
- `close()` removes the channel from the registry; further posts
  don't reach it.

Built on top of v0.49's `EventTarget`, so `addEventListener('message',
fn)` works in addition to the `.onmessage` property.
