## What's new

### `node:test` mock support

Each test gets its own `t.mock` tracker; method/getter/setter mocks
auto-restore at end-of-test:

```js
test('something', (t) => {
  const spy = t.mock.fn((a, b) => a + b);
  spy(2, 3);
  spy.mock.callCount();         // 1
  spy.mock.calls[0].arguments;  // [2, 3]
  spy.mock.calls[0].result;     // 5

  // Replaces obj.greet; auto-restored when this test ends.
  t.mock.method(obj, 'greet', () => 'fake');

  // Property descriptor mocks.
  t.mock.getter(obj, 'now', () => 12345);
  t.mock.setter(obj, 'name', (v) => { /* swallow */ });
});
```

### `cluster` stub

Single-process degenerate. Real cluster needs a master + N workers
sharing a TCP server fd; we have neither. Expose the master half so
libraries branching on `if (cluster.isPrimary)` take the right path:

```js
cluster.isMaster === true
cluster.isPrimary === true
cluster.isWorker === false
cluster.workers === {}
cluster.fork()  // throws
```
