## What's new

Node subpath module aliases that modern packages use as their import
target. Up to v0.69 you had to reach into a parent module
(`require('fs').promises`) — v0.70 lets you write the canonical
`require('fs/promises')` and friends.

| Subpath                         | Resolves to |
|---|---|
| `fs/promises`, `node:fs/promises` | `fs.promises` |
| `path/posix`, `path/win32`         | `path` (POSIX-only runtime) |
| `stream/web`                       | `{ ReadableStream, WritableStream, TransformStream, ByteLengthQueuingStrategy, CountQueuingStrategy }` |
| `stream/promises`                  | `{ pipeline, finished }` (Promise form) |
| `stream/consumers`                 | `{ buffer, arrayBuffer, text, json, blob }` |

`stream/consumers` works over both WHATWG `ReadableStream` and Node
`Readable` streams — drains the source and converts to the named type.

```js
var consumers = require('stream/consumers');
var rs = new ReadableStream({
  start(c) { c.enqueue(new TextEncoder().encode('Hi!')); c.close(); }
});
await consumers.text(rs);   // -> 'Hi!'
```
