## What's new

### NIST ECDH

Closes the last "Still missing" item in the asymmetric-crypto
roster. Builds on v0.75's `elliptic` vendor:

```js
var alice = crypto.generateKeyPairSync('ec', { namedCurve: 'P-256' });
var bob   = crypto.generateKeyPairSync('ec', { namedCurve: 'P-256' });

var sharedAlice = crypto.diffieHellman({
    privateKey: alice.privateKey,
    publicKey:  bob.publicKey
});
var sharedBob = crypto.diffieHellman({
    privateKey: bob.privateKey,
    publicKey:  alice.publicKey
});

sharedAlice.equals(sharedBob);  // true
```

Returns the X coordinate of the derived point as a Buffer,
left-padded to the curve's byte length:

| Curve | Shared secret length |
|---|---|
| P-256 / secp256k1 | 32 bytes |
| P-384 | 48 bytes |
| P-521 | 66 bytes |

Curve mismatch (e.g. P-256 private with P-384 public) raises early.
Non-EC keys (RSA, Ed25519) get a `TypeError`.

### Roster status after v0.76

| Algorithm | Sign | Verify | Encrypt | Decrypt | Agree | Library |
|---|---|---|---|---|---|---|
| RSA       | ✅ | ✅ | ✅ | ✅ |    | forge |
| Ed25519   | ✅ | ✅ |    |    |    | tweetnacl |
| X25519    |    |    |    |    | ✅ | tweetnacl |
| ECDSA P-256/384/521/secp256k1 | ✅ | ✅ |    |    |    | elliptic |
| ECDH  P-256/384/521/secp256k1 |    |    |    |    | ✅ | elliptic |

The asymmetric stack on the runtime is now feature-complete on the
curves we support. RSA / ECDSA / ECDH are slow on G3 (`bn.js` bignum
isn't tuned for 32-bit PowerPC) but functionally correct.
