## What's new

- **`crypto.publicEncrypt` / `crypto.privateDecrypt`** — RSA-OAEP via node-forge. Default md is SHA-1 (Node compatibility). Override per-call: `crypto.publicEncrypt({ key, oaepHash: 'sha256' }, plaintext)`.
- **PEM key import** — `crypto.createPrivateKey('-----BEGIN ...')` / `crypto.createPublicKey('-----BEGIN ...')` parse PEM RSA keys via forge and produce a `KeyObject` that's accepted by `crypto.sign` / `verify` / `publicEncrypt` / `privateDecrypt`.
- **Public-from-private projection** — `crypto.createPublicKey(rsaPrivateKO)` returns the corresponding public KeyObject.
- Both `createPrivateKey` and `createPublicKey` now passthrough an existing matching-type KeyObject.

## Smoke coverage

`rsa_encrypt_smoke.js` exercises:

1. Keygen + publicEncrypt -> privateDecrypt round-trip

4. PEM export -> re-import -> encrypt/decrypt + sign/verify round-trip with the imported keys
5. `createPublicKey(privateKO)` projection round-trip
