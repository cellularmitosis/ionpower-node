v0.19: AES-GCM (authenticated encryption)

Session S. ~130 LOC pure JS.

- _gmul: GF(2^128) multiplication (bit-wise, reducing poly 0xe1..01)
- _ghash: block accumulator
- _aes_gcm_encrypt / _aes_gcm_decrypt: full AEAD per NIST SP 800-38D
- _CipherGCM class: setAAD / setAuthTag / getAuthTag Node API
- Constant-time tag compare on decrypt

NIST GCM Test Case 3 (AES-128 all-zero) passes byte-exact for both
ciphertext and auth tag. Round-trip AES-256-GCM with AAD works.
Tag-mismatch and wrong-AAD both correctly reject.
