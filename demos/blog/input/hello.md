# Hello from the blog

This is the first post in the blog demo. It's built on top of the
ssg v2 pipeline: js-yaml + markdown-it + prism + slugify + handlebars
+ xml2js — seven libraries cooperating on a PowerPC G5.

Subsequent posts go into subdirectories; the builder recurses through
the whole tree.
